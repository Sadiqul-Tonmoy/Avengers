# CampusFlow University Demo Checklist

- [ ] From the folder containing `package.json`, run `npm install` and `npm run build` successfully.
- [ ] Run `npm start` and open http://localhost:4300.
- [ ] Open each sidebar route and verify no blank/error pages.
- [ ] Open Calendar, add a class tomorrow (10:00–11:00), refresh, then see it saved.
- [ ] Open Work Shifts, add a shift tomorrow (10:30–12:00) and verify a warning.
- [ ] Open Conflict Alerts and confirm the overlap 10:30–11:00.
- [ ] Edit the shift to 11:00–12:00 and verify alerts disappear.
- [ ] Delete a shift; verify it disappears from the calendar and stays deleted after refresh.
- [ ] Add an assignment with a due date and course, update its status, and see it in Calendar / To-Do.
- [ ] Add a Campus Event and RSVP, verify it appears in Calendar; withdraw RSVP and confirm it disappears.
- [ ] Add a personal To-Do task, mark complete, edit/delete, refresh to see changes.
- [ ] Open Reminders, toggle settings, refresh and verify preferences are preserved.
- [ ] Resize to a narrow mobile viewport and use the hamburger sidebar.

**Note:** The older “Next Tip / Next development step” banner and other static placeholder pages have been removed.
